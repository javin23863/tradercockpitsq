# Building blocks

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/building-blocks/  
**SQX tab:** Builder › Full settings › Building blocks  
**Kind:** `write`

Core components combined to create strategy rules and actions.

## From official docs

- Check blocks to include; optionally set **Weight** (competing blocks) or **Percentage** (exit methods).
- Select favorite indicators or restrict generation (e.g. price data + operators only).
- **Calibrate before start** triggers indicators calibration on project run.

## Integration

- **Typical artifact:** Builder project XML (BuildingBlocks)
- **Widget:** Block checkboxes, weight/percent, calibrate before start
