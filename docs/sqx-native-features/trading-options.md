## From official docs

- Trading options govern backtesting engine behavior (e.g. close all positions at end of day/week).
- **Store chart data** must be enabled for the Trades on chart results tab.

## Integration

- **Typical artifact:** Builder project XML (TradingOptions)
- **Widget:** EOD close, chart data storage, testing conditions
