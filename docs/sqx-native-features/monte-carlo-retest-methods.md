# Monte Carlo retest methods

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/monte-carlo-retest-methods/  
**SQX tab:** Builder › Cross checks › MC retest  
**Kind:** `native-run`

Monte Carlo simulations with random changes requiring full strategy retest.

## From official docs

- Simulates changes in spread, slippage, parameters, or history data.
- Each simulation requires a complete backtest; runtime scales with simulation count.

## Integration

- **Typical artifact:** Cross-check config; retest simulation results
- **Widget:** Spread/slippage/parameter/data MC retests
