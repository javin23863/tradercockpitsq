# Sequential optimization

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/sequential-optimization/  
**SQX tab:** Optimizer / Cross checks  
**Kind:** `native-run`

Optimization method available as optimization type and cross check (SQX 132).

## From official docs

- Optimizes parameters sequentially instead of all combinations at once (contrast with brute-force or genetic optimization of all parameters together).

## Integration

- **Typical artifact:** Sequential optimization results
- **Widget:** Sequential optimization type/cross check
