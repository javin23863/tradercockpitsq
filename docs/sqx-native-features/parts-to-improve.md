# Parts to improve

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/parts-to-improve/  
**SQX tab:** Builder › Full settings › Parts to improve  
**Kind:** `write`

Configure which parts of an existing strategy to improve and whether to replace or add blocks.

## From official docs

- Visible only when **Improve existing strategy** is selected in What to build.
- Choose Entry rule, Exit rule, or Order type and how each part is improved.

## Integration

- **Typical artifact:** Builder project XML (ImproveExistingStrategy)
- **Widget:** Entry/Exit/Order type improve options; `action` is `add-or-replace` / `replace` / `add` from existing XML
