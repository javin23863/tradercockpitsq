# Recommended optimization parameters

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/recommended-optimization-parameters/  
**SQX tab:** Optimizer / Cross checks  
**Kind:** `write`

Default parameter subset for optimization and cross-check optimizations.

## From official docs

- Default choice when selecting optimization parameter categories.
- Includes indicator periods, entry multipliers, and exit parameters (SL/PT pips/multipliers); other block parameters are ignored to limit overfitting risk.

## Integration

- **Typical artifact:** Optimizer XML parameter selection
- **Widget:** Recommended parameters category
