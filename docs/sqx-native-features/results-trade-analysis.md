# Trade analysis

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/results-trade-analysis/  
**SQX tab:** Builder › Results › Trade analysis  
**Kind:** `read-model`

Yearly performance and configurable trade-distribution charts.

## From official docs

- Charts include trades per hour, day of week, day of month, and related backtest metrics.
- **PL in money by year** is the default yearly chart.

## Integration

- **Typical artifact:** Trade distribution charts; yearly P/L
