# Retest on additional markets

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/retest-additional-markets/  
**SQX tab:** Builder › Cross checks › Additional markets  
**Kind:** `native-run`

Robustness test by running the same strategy on different symbols and/or timeframes.

## From official docs

- A robust strategy should ideally work on multiple symbols/timeframes.
- Practical expectation: at least some profitability or only slight loss on other markets.

## Integration

- **Typical artifact:** Cross-check config; additional-market sample results
- **Widget:** Retest on different symbol/timeframe
