# What to build

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/what-to-build/  
**SQX tab:** Builder › Full settings › What to build  
**Kind:** `write`

Select what to generate: single-chart, multi-TF/multi-symbol, template, or improve existing strategy.

## From official docs

- **Strategy types:** Simple, Multi-TF/multi-symbol, Strategy from template, Improve existing strategy.
- **Trading direction:** Long, Short, or both; symmetrical or non-symmetrical entry/exit rules.
- **Build mode:** Genetic evolution or Random generation (enables Genetic options tab).
- **Generation ranges:** Number of conditions, Shift (lookback), Indicators period, Stop Loss & Profit Target per chart.

## Integration

- **Typical artifact:** Builder project XML (WhatToBuild section)
- **Widget:** Strategy type, direction, build mode, conditions, SL/PT
