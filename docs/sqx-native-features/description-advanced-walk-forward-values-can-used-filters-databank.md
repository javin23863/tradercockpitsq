# Walk-Forward databank columns

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/description-advanced-walk-forward-values-can-used-filters-databank/  
**SQX tab:** Databank › Column editor  
**Kind:** `read-model`

Special stats from Walk-Forward optimization usable in databank filters and columns.

## From official docs

- Standard stats (Net profit, Number of trades, Sharpe ratio, etc.) computed from WFO equity, not main backtest.
- Select **Walk-Forward Matrix** or **Walk-Forward Optimization** in column **From backtest** when editing a column.

## Integration

- **Typical artifact:** Databank column defs from WFO/WFM equity
- **Widget:** WFO/WFM filter and column values
