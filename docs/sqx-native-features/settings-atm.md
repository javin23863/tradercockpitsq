# Advanced Trade Management (ATM)

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/settings-atm/  
**SQX tab:** Builder › Full settings › ATM  
**Kind:** `write`

Advanced Trade Management enables configuration of multiple strategy exits.

## From official docs

- Feature was marked experimental in SQX Build 130 documentation.
- Multiple exits follow a simple sequential logic described in the official page.

## Integration

- **Typical artifact:** Builder project XML (ATM)
- **Widget:** Multiple exit configuration
