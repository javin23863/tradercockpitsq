# Genetic options

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/genetic-options/  
**SQX tab:** Builder › Full settings › Genetic options  
**Kind:** `write`

Visible only when Build mode = Genetic evolution in What to build.

## From official docs

- **Genetic options:** Max # of Generations, Population size, Crossover and Mutation probability.
- **Island options:** Islands, Migrate every Xth generation, Population migration rate.
- **Initial population:** Initial population databank, decimation coefficient, initial population filter.
- **Evolution management / Fresh blood:** Restart when finished, stagnation restart, duplicate/weak-strategy replacement.

## Integration

- **Typical artifact:** Builder project XML (GeneticOptions)
- **Widget:** Generations, population, islands, migration, fresh blood
