# Databanks

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/databank/  
**SQX tab:** Builder / Retester / Optimizer › Databank  
**Kind:** `native-run`

Databanks are storage where generated or tested strategies and their results are kept.

## From official docs

- Each module has independent databanks; capacity is limited (e.g. top 100 or 1000).
- Sort order and capacity are configured in Settings › Ranking options.

## Integration

- **Typical artifact:** Databank store; strategy result bundles
- **Widget:** Load / Save; strategy selection
