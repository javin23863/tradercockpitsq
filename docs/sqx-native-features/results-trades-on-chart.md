# Trades on chart

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/results-trades-on-chart/  
**SQX tab:** Builder › Results › Trades on chart  
**Kind:** `read-model`

History chart with indicators and all orders drawn for visual strategy review.

## From official docs

- Available only when **Store chart data** is enabled in Settings › Trading options.

## Integration

- **Typical artifact:** Stored chart data; orders on OHLC
- **Widget:** Chart with indicators and orders
