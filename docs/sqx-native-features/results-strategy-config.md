# Strategy config diff

**Ingested:** 2026-09-04  
**Source:** https://strategyquant.com/doc/strategyquant/results-strategy-config/  
**SQX tab:** Builder › Results › Strategy config  
**Kind:** `read-model`

Compares current module configuration with the configuration used in the strategy's last backtest.

## From official docs

- Differences are highlighted in red.
- **Apply Strategy Config** loads settings from the strategy into the selected module.

## Integration

- **Typical artifact:** Strategy-embedded config vs current module settings
- **Widget:** Config diff; Apply Strategy Config
