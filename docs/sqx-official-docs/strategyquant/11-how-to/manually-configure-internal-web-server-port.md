# Manually configure internal web server port

- Source: <https://strategyquant.com/doc/strategyquant/manually-configure-internal-web-server-port/>
- Section: StrategyQuant X › How to...
- Fetched: 2026-09-04

---

If you need change the port for web UI you can chage it by adding WebServerPort setting into SQinstall **folder/user/settings/settings.xml**

For Example:

```
<WebServerPort>4971</WebServerPort>
```
