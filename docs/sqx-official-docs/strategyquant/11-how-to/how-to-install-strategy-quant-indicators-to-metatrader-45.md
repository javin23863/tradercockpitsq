# How to install Strategy Quant indicators to Metatrader 4/5

- Source: <https://strategyquant.com/doc/strategyquant/how-to-install-strategy-quant-indicators-to-metatrader-45/>
- Section: StrategyQuant X › How to...
- Fetched: 2026-09-04

---

#### Where are indicators stored?

They are stored in Strategy Quant installation folder, obviously in **C:StrategyQuantXcustom\_indicators**

#### Now we are going to copy them to Metatrader 4/5

Open Metatrader 4/5  platform and go to the File -> Open data folder

[![](https://strategyquant.com/wp-content/uploads/2018/12/Open_data_folder.png)](https://strategyquant.com/wp-content/uploads/2018/12/Open_data_folder.png)

Find the Metratrader 4/5 indicators which are obviously stored in App data folder. In our case we are using portable version of MT4/5  and indicators are stored in these folders:

**MT4 installation folderMQL4 Indicators**

**MT5 installation folderMQL5 Indicators**

[![](https://strategyquant.com/wp-content/uploads/2018/12/folder_indicators.png)](https://strategyquant.com/wp-content/uploads/2018/12/folder_indicators.png)

**Metatrader 4**

Copy indicators from StrategyQuant X **C:StrategyQuantXcustom\_indicatorsMetaTrader4** to **MT4 installation folderMQL4 Indicators**

[![](https://strategyquant.com/wp-content/uploads/2018/12/indicators.png)](https://strategyquant.com/wp-content/uploads/2018/12/indicators.png)

**Metatrader 5**

Copy indicators from StrategyQuant X **C:StrategyQuantXcustom\_indicatorsMetaTrader5** to **MT5 installation folderMQL5 Indicators**

[![](https://strategyquant.com/wp-content/uploads/2018/12/indicatorsmt5.png)](https://strategyquant.com/wp-content/uploads/2018/12/indicatorsmt5.png)

#### **After copying the indicators to Metatrader 4/5 you have restart the platform to compile all indicators and reload into the platform.**
