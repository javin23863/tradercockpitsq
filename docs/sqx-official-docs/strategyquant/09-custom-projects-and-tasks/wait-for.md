# Wait for user/file

- Source: <https://strategyquant.com/doc/strategyquant/wait-for/>
- Section: StrategyQuant X › Custom projects and tasks
- Fetched: 2026-09-04

---

a special task that fill pause the projetc until user unpauses it or until a file appears at a specific path.

Its supposed use is in conjunction with external programs, where you want to pause custom project until some external program(s) do their work. When they finish they can product an empty file to resume work on custom project again.
