# Go To Task

- Source: <https://strategyquant.com/doc/strategyquant/go-to-task/>
- Section: StrategyQuant X › Custom projects and tasks
- Fetched: 2026-09-04

---

a special task that enables creating loops in your tasks workflow – you can use it to skip to another task when certain condiitons are not true – for example when there is not enough strategies in the final strateies, skip to the beginning and run the custom project one more time.
