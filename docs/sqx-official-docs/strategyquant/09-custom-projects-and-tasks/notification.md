# Notification task

- Source: <https://strategyquant.com/doc/strategyquant/notification/>
- Section: StrategyQuant X › Custom projects and tasks
- Fetched: 2026-09-04

---

a special task that can display a notification or send you an email when project gets to a certain point.

It can also optionally pause the project and wait until user starts it again. It can be used for example when you want to manually review the generated strategies before going further with the tasks.

Or you can use it to get a notification by email when your custom project finishes.
