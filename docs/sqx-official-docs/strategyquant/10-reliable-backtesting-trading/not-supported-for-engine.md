# Not supported for engine

- Source: <https://strategyquant.com/doc/strategyquant/not-supported-for-engine/>
- Section: StrategyQuant X › Reliable backtesting & trading
- Fetched: 2026-09-04

---

Some building blocks are not supported for every engine. Different trading platforms have different features, and some features are supported only on particular trading platform.

Because of this there are some blocks or parameters that are not supported on some trading engines.

Such blocks/parameters are indicated by red flag as in the example below:

[![Block not supported for engine](https://strategyquant.com/wp-content/uploads/2020/07/eng_not_supported-1-1024x160.png)](https://strategyquant.com/wp-content/uploads/2020/07/eng_not_supported-1-1024x160.png)
