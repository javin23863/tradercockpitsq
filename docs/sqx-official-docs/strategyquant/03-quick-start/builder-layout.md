# Builder layout

- Source: <https://strategyquant.com/doc/strategyquant/builder-layout/>
- Section: StrategyQuant X › Quick start
- Fetched: 2026-09-04

---

When you click for example on Builder you’ll see that the screen is divided into three main columns or sections:

[![Strategyquant Builder Screen](https://strategyquant.com/wp-content/uploads/2019/01/builder_screen-1.png)](https://strategyquant.com/wp-content/uploads/2019/01/builder_screen-1.png)

1. **Engine** – this is where you can start or stop the task, see what’s going on in log and progress
2. **Settings** – this is the brief description of actual configuration of Builder, you can click on each of these tabs to view the full configuration
3. **Results** – up to three mini panels with results of the top three strategies currently existing in databank. These mini panels are only a preview of most important strategy statistics. You can get detailed results by clicking on this panel or double-clicking on a strategy in databank.
4. **Databank** – a place where all strategies are stored
