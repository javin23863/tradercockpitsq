# Results – Strategy config

- Source: <https://strategyquant.com/doc/strategyquant/results-strategy-config/>
- Section: StrategyQuant X › Program screens
- Fetched: 2026-09-04

---

This screen displays current config of the module versus configuration that was used in the last strategy backtest. The differences are highlighted with **red** color.

This way you can quickly see any differences between configurations.

[![StrategyQuant strategy result apply strategy config](https://strategyquant.com/wp-content/uploads/2020/05/strategy_config.png)](https://strategyquant.com/wp-content/uploads/2020/05/strategy_config.png)

To load config from the strategy you can use the button **Apply Strategy Config**. This will load settings from the strategy and applies it to the selected module.
