# Results – Trades on chart

- Source: <https://strategyquant.com/doc/strategyquant/results-trades-on-chart/>
- Section: StrategyQuant X › Program screens
- Fetched: 2026-09-04

---

Displays complete chart data for the backtest, so you will be able to see history chart with backtest with used all indicators and all orders drawn on chart. This can help you review the strategy and see visually how it is trading.

[![Strategyquant trades on chart](https://strategyquant.com/wp-content/uploads/2019/01/trades_on_chart.png)](https://strategyquant.com/wp-content/uploads/2019/01/trades_on_chart.png)

Note that this tab is available only if you explicitly configure SQ to save chart data in **Settings** -> **Trading options** -> **Store chart data**:

[![SQ Store chart data setting](https://strategyquant.com/wp-content/uploads/2020/05/store_chart_data.png)](https://strategyquant.com/wp-content/uploads/2020/05/store_chart_data.png)
