- Section: StrategyQuant X › Program screens
- Fetched: 2026-09-04

---

Settings for every part of the program are displayed in tabs on the top row.

[![StrategyQuant settings](https://strategyquant.com/wp-content/uploads/2019/01/settings_main-1024x168.png)](https://strategyquant.com/wp-content/uploads/2019/01/settings_main-1024x168.png)

You can see more detailed settings by clicking to one of the tabs, it will open panel with settings details.

### Load/Save project configuration

You can save your current project configuration to a file and load it from the file later in the Progress tab:

[![SQ config load / save](https://strategyquant.com/wp-content/uploads/2019/01/config_load_save.png)](https://strategyquant.com/wp-content/uploads/2019/01/config_load_save.png)
