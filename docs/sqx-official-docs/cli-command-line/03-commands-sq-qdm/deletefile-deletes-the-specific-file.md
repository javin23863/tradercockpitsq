# -deletefile Deletes the specific file

- Source: <https://strategyquant.com/doc/cli-command-line/deletefile-deletes-the-specific-file/>
- Section: CLI (command line) › Commands (SQ & QDM)
- Fetched: 2026-09-04

---

Deletes a specified file. Could be used in conjunction with **-waitfor** command.

Arguments:

**file**: Path of the file or folder

Example:

```
sqcli.exe -deletefile file=C:/reports/evaluate.txt
```
