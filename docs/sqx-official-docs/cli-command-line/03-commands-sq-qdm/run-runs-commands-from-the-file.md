# -run Runs commands from the file

- Source: <https://strategyquant.com/doc/cli-command-line/run-runs-commands-from-the-file/>
- Section: CLI (command line) › Commands (SQ & QDM)
- Fetched: 2026-09-04

---

Arguments:

**file**: Path of the file

Where file is a text file containing multiple CLI commands separated by lines

Example:

```
sqcli.exe -run file=C:/data/commands.txt
```
